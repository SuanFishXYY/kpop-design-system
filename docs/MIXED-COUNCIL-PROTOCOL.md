# 🎭 Mixed Council Protocol · 混合议会协议

> 这是 KPOP Design System 的核心审议协议。读它，你就懂一场 idol 议会从召集到判决的每一条规则。配套看 [EXAMPLE-COUNCIL-TRANSCRIPT](./EXAMPLE-COUNCIL-TRANSCRIPT.md) 里一场真实的完整记录，规则就活了。

## 这是什么（30 秒）

一场"混合议会"由三种**对等成员**组成，每人一票：

- **idol 担当**（`agents/`）—— 主力 / 辅助 idol，按设计专长被召集
- **团代表**（`groups/`）—— 团魂，承载集体审美 DNA，有否决权
- **用户票席** —— 你，有 veto / override / 偏好学习权

外加一个不投票的主持人（Chair）跑流程。下面是召集、发言、质询、判决的全部规则。

## Assembly

- DRI: group match -> group DRI; style/idol match -> idol DRI; agency match -> brand DRI; fallback -> stage-director.
- Invitation expansion: breadth-first, 3 layers, max 3 single-round invites.
- Council cap: 5 members by default; 7 when the brief spans generations or agencies.
- Mix requirement: councils with 4+ members must include at least 2 idols and 2 groups.
- Same-agency hard cap: no more than 3 groups from one agency.

## Sister group relations

1. `same_generation`: derived from group `era`.
2. `same_agency`: derived from group `agency`.
3. `same_aesthetic`: derived from overlapping `aesthetic_tags`.
4. `aesthetic_counterpoint`: elegant rival relation from `rivals` + `counterpoint_axis`.

## Voice templates

Top groups can provide `voice.identity`, `voice.position_statement`, hard `voice.veto_triggers`, and `voice.question_template`. LLM voice stays soft; veto triggers are deterministic.

## Deliberation

- R1 independent statements: <=200 tokens/member. Each statement is a first-person in-character line derived from the member's tone + signature phrase + negotiation levers + hard veto.
- R2 cross-examination: <=300 tokens/pair. Each directed pair has both a host-AI `question` prompt and a deterministic `reply` line generated by `speakReply(speaker, target)`.
- R2b counter-rebuttals (optional): <=300 tokens/pair. Each R2 target fires back at the challenger with `speakReply(target, speaker)`, producing a second exchange.
- R3 merged declaration: <=150 tokens/member. A final in-character stance line synthesizing R1/R2/R2b tension.
- No R4. Total cap: 4550 estimated tokens without R2b; with R2b the budget scales by the number of directed pairs.

## Verdict

- Consensus: >=2/3 agree.
- Compromise: >1/2 accept.
- Dissent: retained for user judgment.
- Voting: each member one vote + user one vote; PASS requires strict `> 2/3` excluding abstain from denominator.
- Chair abstain is invalid.
- User veto/override remains explicit and audited.
